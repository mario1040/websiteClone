# Mina Saad — Website Recreation

An unofficial responsive front-end recreation study inspired by the publicly visible Mina Saad website.

## Run locally

```bash
npm run start
```

Open the local URL printed by `serve`. For a quick syntax check, run `npm run check`.

## Deployment

This is a static site and can be deployed using GitHub Pages. In repository settings, choose **Deploy from a branch**, select `main` and `/ (root)`.

## Notes

The page uses custom CSS illustrations and does not bundle proprietary source code or private data from the reference site. Publicly visible copy and project details should be verified against the original before claiming a pixel-perfect match. This is an unofficial recreation study.
